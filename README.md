# Web de Ángela García · Psicóloga Sanitaria

Web estática hecha con Eleventy y publicada en Cloudflare Pages. El contenido se edita desde `/admin` (Sveltia CMS).

- `contenido/` → textos de las páginas, preguntas frecuentes y talleres.
- `plantillas/` → diseño (plantillas) y datos generales (contacto, menú).
- `assets/` → estilos, imágenes y scripts.
- `admin/` → panel de edición.

Las carpetas `content/` y `src/` pertenecen a la primera versión de prueba y ya no se usan (se pueden borrar).
